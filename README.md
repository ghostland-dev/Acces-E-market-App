# Energy Market

Energy market web application built with AdonisJS, with a companion Python data API.

## Features

- Market alerts and ARENH data management
- Full authentication flow (login, email verification, password reset)
- REST API controllers
- Python service for data processing

## Tech Stack

- AdonisJS
- PHP
- Python
- Shell
- GitHub Actions

## Getting Started

```bash
git clone https://github.com/ghostland-dev/energy-market-adonis.git
cd energy-market-adonis
python -m venv .venv && source .venv/bin/activate
pip install -r API/requirements.txt
python app.py
```
